# Java Todo App

Basit bir Java Spring Boot Todo API uygulaması.  
Kullanıcılar görev ekleyebilir, listeleyebilir ve silebilir.

---

## Özellikler

- GET /todos → Tüm görevleri listele
- POST /todos → Yeni görev ekle
- DELETE /todos/{id} → Görev sil
- GET /hello?name=Ali → Parametreli test endpoint

---

## Teknolojiler

- Java 17
- Spring Boot 3
- Maven
- Postman (test için)
